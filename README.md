# claude-docs

[Claude Code 공식 문서](https://code.claude.com/docs)를 **오프라인 스냅샷**으로 만드는 도구입니다.
인터넷에 잠깐 연결해 한 번 실행하면, 그날 기준의 문서 전체를 원문 JSON과 오프라인 HTML 사이트로 저장합니다.

- 파이썬 표준 라이브러리만 사용합니다 (설치할 패키지 없음).
- 서버 없이 `file://`로 열립니다.
- 실행할 때마다 직전 스냅샷 대비 **무엇이 바뀌었는지** 로그로 남깁니다.

## 요구 사항

- Python 3.9 이상
- 실행하는 동안만 인터넷 연결

## 사용법

```
python build_docs_snapshot.py
```

약 10초~2분 걸립니다. 어느 폴더에서 실행해도 같습니다.

1. 인터넷에 연결합니다.
2. 위 명령을 실행합니다.
3. 연결을 끊고 `output/index.html`을 엽니다. 항상 최신 스냅샷으로 이동합니다.

출력·로그 폴더를 바꾸려면 `python build_docs_snapshot.py [출력폴더] [로그폴더]`로 지정합니다.

## 결과물

```
output/
├─ index.html              최신 스냅샷의 HTML 로 이동하는 바로가기
├─ history/                날짜별 docs.json.gz 와 전체 diff (최근 30회분)
│  ├─ YYYY-MM-DD.json.gz
│  └─ YYYY-MM-DD.diff      직전 이력 대비 바뀐 페이지의 unified diff (변경이 있을 때만)
└─ YYYY-MM-DD/
   ├─ docs.json            문서 원문 전체 (페이지별 분류, 본문, 메뉴 이름 등)
   ├─ assets/              문서의 이미지·동영상
   └─ html/                오프라인 HTML 사이트
logs/
└─ YYYY/YYYY-MM-DD_HHMMSS.log   실행 1회당 로그 1개
```

- `output/`에는 **최신 스냅샷 폴더 하나만** 남습니다. 성공한 빌드 뒤에 이전 날짜 폴더는 지워집니다. 대신 `history/`에 날짜별 `docs.json`을 gzip(약 3MB)으로 **최근 30회분** 보관하므로 과거 본문을 복원하고 비교할 수 있습니다. 보관 개수는 `build_docs_snapshot.py`의 `KEEP_HISTORY`입니다.
- `html/` 사이트: 좌측 사이드바(페이지 이름 필터와 **본문 검색**), 코드 **구문 강조**(bash·json·python·js/ts·yaml·toml·powershell), 코드 복사 버튼, 다크 모드 자동 대응, 좁은 화면용 메뉴 토글이 있고, 각 페이지 하단에 원문 주소와 스냅샷 날짜가 표시됩니다. 목차에 없는 숨은 페이지도 함께 수집하며(목차의 `Unlisted`), 옛 주소로 걸린 링크는 새 주소로 연결됩니다.
- 로그에는 결과, 수집 요약, 직전 스냅샷 대비 변경 요약(추가·삭제·바뀐 페이지와 섹션), 콘솔 출력이 들어갑니다. 바뀐 내용의 전문은 `history/YYYY-MM-DD.diff`에 있고, 로그에는 그 경로가 적힙니다.
- `output/`은 git에 올라가지 않습니다(`.gitignore`). 필요하면 직접 실행해서 만드세요. `logs/`도 git에 올라가지 않으므로 실행해도 `git status`가 바뀌지 않습니다. 로그는 로컬에만 쌓입니다.

## 안전장치

- 아래 경우에는 기존 스냅샷을 건드리지 않고 종료 코드 1로 끝나며, 로그 파일만 남습니다.
  - 인터넷에 연결되지 않음
  - 수집에 실패한 페이지가 하나라도 있음
  - 변환한 HTML에 없는 파일을 가리키는 내부 링크가 있음
  - 예상하지 못한 오류 (트레이스백이 로그에 기록됨)
- 빌드는 `output/.building/`에서 하고, 모든 페이지 수집·변환이 성공했을 때만 결과를 옮깁니다. 실패하면 기존 스냅샷은 그대로입니다.
- 이미지·동영상 다운로드 실패는 빌드를 멈추지 않습니다. 로그의 수집 요약(에셋 실패 수)에만 기록됩니다.
- 같은 날 다시 실행하면 그날 스냅샷과 이력을 덮어씁니다. 비교 대상은 **오늘 이전의 가장 최근 이력**이라, 다시 실행해도 어제 대비 변경이 그대로 나옵니다. (이력이 아직 없는 최초 실행 직후에는 스냅샷 폴더와 비교하므로 변경이 거의 없게 나올 수 있습니다.)

## 구성

| 파일 | 역할 |
|---|---|
| `build_docs_snapshot.py` | 통합 진입점. 수집 → HTML 변환 → 이전 스냅샷 정리 → 로그 |
| `docs_fetch_json.py` | `llms.txt`에서 페이지 목록을 읽어 원문(.md)과 에셋을 받아 JSON으로 저장 |
| `docs_json_to_html.py` | JSON을 정적 HTML 사이트로 변환 (마크다운 변환기 내장) |
| `docs_diff.py` | 보관된 이력 두 개를 비교해 페이지별 diff 출력 (빌드도 이 모듈로 diff 저장) |
| `docs_common.py` | 수집기·변환기가 공유하는 URL 규칙, 콘솔 UTF-8 설정 |
| `tests/` | 표준 라이브러리 `unittest` 테스트 (네트워크 불필요) |

단계별로 따로 실행할 수도 있습니다.

```
python docs_fetch_json.py output/YYYY-MM-DD/docs.json
python docs_json_to_html.py output/YYYY-MM-DD/docs.json output/YYYY-MM-DD/html
```

보관한 두 날짜의 차이를 보려면(페이지 slug는 선택):

```
python docs_diff.py 2026-11-20 2026-11-27 en/hooks
```

테스트와 콘솔 인코딩:

```
python -m unittest discover tests
```

스크립트는 시작할 때 콘솔을 UTF-8·줄 단위 버퍼로 바꿔서 한글이 깨지지 않고 출력 순서도 유지됩니다. 오래된 PowerShell 5.1에서 직접 눈으로 볼 때 깨지면 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`을 먼저 실행하세요.

## 알려진 한계

- 구문 강조는 규칙 기반의 간단한 방식이라 언어 문법을 완전히 해석하지는 않습니다. 지원하지 않는 언어는 색 없이 표시됩니다.
- 본문 검색은 부분 문자열 일치(공백으로 나눈 단어 모두 포함)이며 형태소 분석이나 오타 보정은 없습니다. 첫 검색 때 색인(약 10MB)을 한 번 불러옵니다.
- 일부 앵커 링크(약 470건)는 원문 사이트에서 헤딩이 바뀌었거나 아코디언 제목에서 나온 것이라 복원할 수 없습니다. 빌드 마지막에 건수가 출력됩니다.
- 로그의 변경 요약은 섹션(헤딩)·줄 단위의 규칙 기반 비교이며 문장 요약이 아닙니다. 확정이 아니라 단서로 보고, 전문은 `history/*.diff`나 `docs_diff.py`로 확인하세요.
- 수집하지 않는 것: GitHub 저장소 `anthropics/claude-code`의 `CHANGELOG.md`, `plugins/`, `examples/` (변경이 너무 잦거나 문서와 중복).
- 스냅샷 날짜는 실행한 PC의 로컬 날짜 기준입니다.

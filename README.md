# claude-docs

![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-blue) ![stdlib only](https://img.shields.io/badge/dependencies-none-brightgreen) [![MIT](https://img.shields.io/badge/license-MIT-lightgrey)](LICENSE)

**[Claude Code 공식 문서](https://code.claude.com/docs)를 오프라인 사이트로 저장하는 도구입니다.**

- 영어판과 공식 한국어판을 함께 저장합니다. 한국어는 번역이 아니라 공식 한국어 문서 원문입니다.
- 서버 없이 브라우저로 바로 열립니다.
- 실행할 때마다 지난번과 달라진 내용을 기록합니다.

## 빠른 시작

```
python build_docs_snapshot.py
```

1. 인터넷에 연결합니다. 실행하는 동안만 필요합니다.
2. 위 명령을 실행합니다. 10초에서 2분쯤 걸립니다.
3. 연결을 끊고 `output/index.html`을 엽니다. 상단의 언어 선택으로 영어와 한국어를 바꿉니다.

Python 3.9 이상만 있으면 됩니다. 설치할 패키지는 없습니다.
출력·로그 폴더는 `python build_docs_snapshot.py [출력폴더] [로그폴더]`로 바꿀 수 있습니다.

## 기능

- **공식 사이트와 같은 화면**: 상단 탭, 사이드바, 탭·아코디언·카드, 다크 모드, 좁은 화면 대응
- **본문 검색**: 헤더의 검색 버튼 또는 `Ctrl K`
- **이 페이지 목차**: 스크롤을 따라 강조됩니다
- **변경 내역**: 지난 실행과 비교해 추가·삭제·수정된 페이지를 보여 줍니다 (`en/changes.html`, `ko/changes.html`)
- **코드 블록**: 구문 강조와 복사 버튼, 페이지 전체 마크다운 복사
- **숨은 페이지와 옛 주소**: 목차에 없는 페이지도 수집하고, 옛 주소 링크는 새 주소로 연결합니다
- **한국어판이 없는 페이지**(현재 `changelog`, `claude-tag`): 안내 문구와 함께 영어 원문을 보여 줍니다

## 결과물

- `output/index.html`: `site/`로 가는 바로가기
- `output/site/`: 오프라인 사이트 (브라우저로 여는 폴더)
- `output/history/`: 날짜별 원본 데이터와 변경 diff (최근 30회분)
- `logs/`: 실행 1회당 로그 1개

`output/`과 `logs/`는 git에 올라가지 않으니 직접 실행해서 만드세요.

- 로그에는 결과, 수집 요약, 지난번 대비 변경 요약, 링크 검증 결과가 들어 있습니다.
- 보관 개수는 `docsnap/build.py`의 `KEEP_HISTORY`로 바꿉니다.

## 실패해도 안전합니다

인터넷이 없거나, 페이지 수집에 실패했거나, 링크 검증에서 문제가 나오면 **기존 사이트는 그대로 두고** 로그만 남긴 채 종료합니다. 모두 성공했을 때만 사이트를 교체합니다.

## 오프라인 동작

- **되는 것**: 이미지, 동영상, CSS, 글꼴이 모두 로컬에 있어서 메뉴, 목차, 검색, 복사, 다크 모드, 변경 내역이 인터넷 없이 동작합니다.
- **안 되는 것**: 본문 안의 외부 링크(claude.com, github.com 등)와 각 페이지 하단의 "원문" 링크는 인터넷이 있어야 열립니다.
- **크기**: 사이트 약 80MB, 이력은 하루 약 6MB입니다.
- **최신성**: 사본은 실행한 날 기준이며 자동으로 갱신되지 않습니다.

## 알려진 한계

- 구문 강조는 규칙 기반이라 지원하지 않는 언어는 색 없이 표시됩니다.
- 검색은 단어 포함 여부만 봅니다. 오타 보정은 없습니다.
- 공식 사이트의 "Ask Assistant"와 웹폰트는 없습니다.
- 공식 문서에서 사라진 섹션으로 가는 링크는 페이지 처음으로 연결하고 점선 밑줄로 표시합니다. 건수는 로그의 "링크 검증"에서 봅니다.
- 변경 요약은 섹션·줄 단위의 규칙 기반 비교입니다. 정확한 내용은 `history/*.diff`에서 확인하세요.
- Windows에서 브라우저나 탐색기가 `output/site`를 열고 있으면 마지막 교체 단계가 막힐 수 있습니다. 먼저 닫고 실행하세요.
- 접근성은 자동 검사와 키보드 조작으로만 확인했고, 스크린 리더로는 확인하지 않았습니다.

## 그 밖의 명령

```
python docs_diff.py 2026-11-20 2026-11-27 ko/hooks   # 두 날짜의 차이 (페이지는 선택)
python docs_verify.py output/site                    # 만든 사이트의 링크 검사
```

오래된 PowerShell에서 한글이 깨지면 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`을 먼저 실행하세요.

## 참고

- 코드는 [MIT 라이선스](LICENSE)입니다. 수집되는 Anthropic 문서에는 적용되지 않습니다.
- 이 도구는 **비공식**이며 Anthropic과 관련이 없습니다. Claude, Claude Code는 Anthropic의 상표입니다.
- 문서의 내용과 이미지의 저작권은 Anthropic에 있습니다. `output/`은 개인 열람용으로만 쓰고 재배포하지 마세요.
- 이 저장소에는 문서 사본이 없고 수집 도구만 있습니다.
